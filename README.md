# СКВОЗНИКИ

Сайт школьного ток-шоу НИШ IB (Астана). Ученики оставляют три вида заявок: «Хочу в выпуск», «Идея для выпуска» и «Новость школы». Команда разбирает их в закрытой админке. На сайте появляется только то, что ведущие одобрили вручную.

Стек: Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · Motion · Supabase · Vercel.

## Быстрый старт (демо-режим, без базы)

```bash
npm install
npm run dev
```

Откройте http://localhost:3000. Без переменных Supabase сайт работает на примерных данных в памяти сервера. Админка: http://localhost:3000/admin, пароль `efir` (только в dev; в production задайте `DEMO_ADMIN_PASSWORD`, иначе админка выключена). Данные демо-режима пропадают при перезапуске, поэтому для реального запуска нужен Supabase.

## Как переименовать шоу

Всё в одном файле: `src/config/site.ts` → `name`, `nameLatin`, `nameLines` (как название делится на две строки в hero). Там же ведущие, соцсети и фото.

Фото ведущих: положите `public/hosts/yerkin.jpg` и т. д. и укажите `photo: "/hosts/yerkin.jpg"`. Пока фото нет, карточка рисует цветную монограмму.

Все тексты на трёх языках лежат в `src/i18n/dictionary.ts`. Русский — эталон: если в казахском или английском не хватает ключа, TypeScript не даст собрать проект.

## Подключение Supabase

1. Создайте проект на https://supabase.com (регион Frankfurt ближе всего к Астане).
2. **SQL Editor** → вставьте `supabase/migrations/0001_init.sql` целиком → **Run**. Миграция создаёт таблицы, Row Level Security, функции и приватный bucket `news-photos`.
3. Добавьте ведущих в список админов (там же, в SQL Editor):
   ```sql
   insert into public.admins (email) values
     ('yerkin@example.com'), ('khamza@example.com'), ('asanali@example.com');
   ```
4. **Authentication → Users → Invite user**: пригласите эти же три email. Самостоятельная регистрация выключена (`shouldCreateUser: false`), посторонний не сможет создать аккаунт.
5. **Authentication → URL Configuration**: Site URL = адрес сайта; в Redirect URLs добавьте `https://ВАШ-ДОМЕН/auth/callback` и `http://localhost:3000/auth/callback`.
6. **Project Settings → API**: скопируйте URL, `anon` key и `service_role` key в переменные окружения (ниже).

Вход в админку: `/admin` → email → письмо со ссылкой → готово.

### Кто что может (RLS)

| Роль | Права |
|---|---|
| Аноним (сайт) | `INSERT` в три таблицы заявок, только в «ученические» колонки (статус, публикацию и голоса подделать нельзя). `SELECT` только одобренных и опубликованных строк и только публичных колонок: имена авторов идей, тексты анонимных новостей и заметки команды наружу не уходят. |
| Ведущие (`public.admins`) | Всё, через `public.is_admin()`. |
| Сервер (`service_role`) | Только `cast_vote` и `hit_rate_limit` (голоса и общий rate-limit). |

На уровне базы стоят защитные ограничения: опубликовать можно только одобренное (`check`), а у анонимной новости не может быть имени.

## Переменные окружения

Скопируйте `.env.example` в `.env.local` (локально) или добавьте в Vercel → Settings → Environment Variables:

| Переменная | Зачем |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | Адрес сайта: QR-плакат и превью ссылок |
| `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Включают Supabase вместо демо-режима |
| `SUPABASE_SERVICE_ROLE_KEY` | Голосование и общий rate-limit. Только на сервере, в браузер не попадает |
| `HASH_SALT` | Случайная строка (`openssl rand -hex 32`): соль для хешей IP и устройств |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | Необязательно: уведомление в чат команды о каждой заявке |
| `DEMO_ADMIN_PASSWORD` | Только для демо-режима без Supabase |

**Telegram-бот:** создайте бота у @BotFather и добавьте его в чат команды. Затем напишите в чат любое сообщение, откройте `https://api.telegram.org/bot<TOKEN>/getUpdates` и возьмите `chat.id` (для групп он отрицательный). Если токена нет, уведомления просто пропускаются.

## Деплой на Vercel

1. Импортируйте репозиторий в Vercel (Framework: Next.js, настройки по умолчанию).
2. Добавьте переменные из таблицы выше.
3. Deploy. После первого деплоя пропишите итоговый домен в `NEXT_PUBLIC_SITE_URL` и в Redirect URLs Supabase.
4. Откройте `/qr`, нажмите «Распечатать»: получится A4-плакат с QR на главную. Для типографии есть «Скачать SVG».

## Защита и приватность

- **Honeypot**: скрытое поле, которое заполняют только боты; такие заявки молча «принимаются» и не сохраняются.
- **Time-trap**: заявка, отправленная быстрее 2,5 с после открытия формы, считается ботом.
- **Rate-limit**: не больше 5 заявок в час с одного IP. IP хранится только как солёный хеш, сутки.
- **zod на клиенте и сервере**: одна и та же схема (`src/lib/schemas.ts`).
- **Фото**: перед отправкой перекодируются в браузере через canvas, поэтому из них удаляются геолокация и данные камеры. Для анонимной новости это важно: GPS в EXIF может выдать автора. На сервере проверяется реальная сигнатура файла, а не только заявленный тип.
- **Минимум данных**: без фамилии, телефона и ИИН. Анонимная новость не хранит ни имени, ни IP.
- **CSV-экспорт** с BOM (Excel правильно открывает кириллицу и казахские буквы) и защитой от формул (CSV injection).
- **Голоса**: один на идею с устройства (httpOnly-cookie, хранится хеш). Ограничение по IP намеренно не используется: вся школа выходит в интернет через пару Wi-Fi-адресов.

## Проверка качества

```bash
npm run build && npm start
node scripts/qa.mjs http://localhost:3000
```

`scripts/qa.mjs` (нужен Playwright с Chromium) делает две проверки:
1. Через DevTools-протокол спрашивает Chromium, **каким шрифтом на самом деле нарисованы** Ә Ғ Қ Ң Ө Ұ Ү Һ І, и падает, если хоть одна буква ушла в запасной шрифт.
2. Ищет горизонтальную прокрутку и вылезающие заголовки на всех страницах × 3 языка × ширины 320 / 375 / 1440.

### Шрифты

- **Science Gothic** (заголовки, оси ширины и веса) + **Onest** (текст), OFL.
- Отбор: Unbounded, Dela Gothic One, Russo One, Rubik Mono One и Wix Madefor не поддерживают казахские буквы, поэтому отбракованы. Science Gothic и Onest прошли проверку на всех 18 глифах.
- Подмножества вырезаны `pyftsubset` в `public/fonts` (~135 КБ на всё), разбиты по `unicode-range`: казахский файл грузится, только когда на странице есть казахские буквы.
- Заголовки сами подгоняют кегль под длину самого длинного слова (`src/lib/fit.ts`): казахские слова длиннее русских.

## Структура

```
src/
  app/(site)/[lang]/   публичный сайт: / (ru), /kk, /en; join, idea, news, qr
  app/(admin)/admin/   админка
  app/api/             submit, vote, admin/*
  components/site/     hero (вентилятор + ветер), ticker, doors, hosts, episodes, ideas…
  components/forms/    поля, движок отправки, экран успеха, сжатие фото
  lib/repo/            demo.ts (память) и supabase.ts за одним интерфейсом
  proxy.ts             языки и обновление сессии админки
supabase/migrations/   SQL: таблицы, RLS, RPC, storage
```

Публичные страницы — ISR (`revalidate = 60`). Публикация в админке сбрасывает кэш, и изменения видны со следующего открытия страницы.
